# Scientific Calculator Using Java

A beginner-friendly, console-based scientific calculator developed using Java. It performs basic arithmetic operations and scientific calculations such as square roots, powers, sine, cosine, and natural logarithms. The project demonstrates Java programming fundamentals, including loops, switch-case statements, user input handling, and the Math library.

## Features
- Basic arithmetic operations
- Square root and exponentiation
- Trigonometric calculations (sine and cosine)
- Natural logarithm
- Input validation and basic error handling

## Technologies Used
- Java
- Java Math Library
- Visual Studio Code

## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project folder in VS Code.
3. Open the terminal and compile the program:
   `javac ScientificCalculator.java`
4. Run the program:
   `java ScientificCalculator`

## Purpose
This project was created to practice Java fundamentals and develop problem-solving skills through a simple, interactive application.
